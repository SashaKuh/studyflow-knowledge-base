# CLI

Командний інтерфейс обробляє `add`, `list`, `done`, `summary`, `export`, `upcoming --days N`, показує помилки й делегує зберігання [[SQLite-сховище]].

## Команди
- `add` — додає [[Навчальна задача]].
- `list` — показує задачі.
- `done` — позначає задачу виконаною.
- `summary` — підсумок за задачами.
- `export` — експортує задачі.
- `upcoming --days N` — показує задачі з дедлайном у найближчі N днів.

## Відношення
- [[CLI]] depends_on [[SQLite-сховище]].
- [[CLI]] implements [[Навчальна задача]].
