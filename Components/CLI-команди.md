# CLI-команди

Набір CLI-команд StudyFlow для керування навчальними задачами:

- `add` — додає нову навчальну задачу (назва, курс, дедлайн).
- `list` — виводить список задач.
- `done` — позначає задачу як виконану.
- `summary` — показує зведення за задачами (кількість виконаних/невиконаних).
- `export` — експортує задачі у CSV-файл.
