# CLI-команди

Набір CLI-команд StudyFlow для керування навчальними задачами:

- `add` — додає нову навчальну задачу (назва, курс, дедлайн).
- `list` — виводить список задач.
- `done` — позначає задачу як виконану.
- `summary` — показує зведення: відкриті, завершені та прострочені задачі.
- `export` — експортує задачі у CSV-файл.
- `upcoming --days N` — показує відкриті задачі з терміном від сьогодні до сьогодні + N днів включно, відсортовані за дедлайном. Команда лише читає дані через `TaskStore.list(status='open')` і нічого не записує в базу; від'ємне N відхиляється.

Логіка фільтрації `upcoming` винесена в модуль `studyflow/upcoming.py` (див. [[Фільтрація upcoming в окремому модулі]]).
